# АвтоУход - Премиальный автосервис

Современный веб-сайт для премиального автосервиса "АвтоУход" с интерактивным каталогом услуг, личным кабинетом и системой онлайн-записи.

## 🚀 Особенности

- **Полнофункциональный каталог услуг** с фильтрацией по категориям
- **Интерактивная корзина** с расчетом стоимости в реальном времени
- **Личный кабинет** с историей заказов и бонусами
- **Адаптивный дизайн** для всех устройств
- **Темная тема** с золотыми акцентами
- **Анимации и интерактивные элементы**
- **Мобильное меню**
- **Формы авторизации и регистрации**

## 🛠 Технологии

- HTML5, CSS3 (Grid, Flexbox, Custom Properties)
- JavaScript (ES6+)
- LocalStorage для хранения данных
- Font Awesome иконки
- Google Fonts (Montserrat, Playfair Display)
- GitHub Pages для хостинга

## 📁 Структура проекта

- `index.html` - Основной файл сайта
- `404.html` - Страница 404 ошибки
- `sitemap.xml` - Карта сайта
- `robots.txt` - Инструкции для поисковых роботов
- `assets/` - Статические файлы (изображения, CSS, JS)

## 🚀 Развертывание на GitHub Pages

1. Создайте новый репозиторий на GitHub
2. Загрузите все файлы проекта
3. Перейдите в Settings → Pages
4. В разделе "Source" выберите ветку `main`
5. Сайт будет доступен по адресу: `https://ваш-логин.github.io/имя-репозитория/`
