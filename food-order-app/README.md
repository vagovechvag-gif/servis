# Приложение заказа еды для VK Mini Apps

Простое приложение для заказа еды, разработанное на React с использованием библиотеки VKUI.

## 📋 Описание

Приложение включает в себя:
- **Главная страница (Меню)**: Список товаров по категориям (ШАУРМА, БУРГЕРЫ, ШАШЛЫК)
- **Корзина**: Отображение выбранных товаров и итоговой суммы
- **Оформление заказа**: Форма с полями "Имя" и "Телефон"
- **Отправка заказа**: Формирование JSON и отправка через VK Bridge или тестовый alert

## 🚀 Быстрый старт

### Локальный запуск

1. **Установите зависимости:**
   ```bash
   cd food-order-app
   npm install
   ```

2. **Запустите проект в режиме разработки:**
   ```bash
   npm run dev
   ```

3. **Откройте браузер** по адресу `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы появятся в папке `dist/`.

## 🌐 Размещение на хостинге

### GitHub Pages

1. **Установите gh-pages:**
   ```bash
   npm install --save-dev gh-pages
   ```

2. **Добавьте в package.json:**
   ```json
   {
     "homepage": "https://yourusername.github.io/food-order-app",
     "scripts": {
       "predeploy": "npm run build",
       "deploy": "gh-pages -d dist"
     }
   }
   ```

3. **Разверните:**
   ```bash
   npm run deploy
   ```

4. **В настройках репозитория GitHub:**
   - Settings → Pages
   - Source: Deploy from a branch → gh-pages branch

### Vercel

1. **Установите Vercel CLI:**
   ```bash
   npm install -g vercel
   ```

2. **Разверните проект:**
   ```bash
   vercel
   ```

3. **Следуйте инструкциям в терминале**

Vercel автоматически определит Vite и настроит сборку.

## 🔗 Подключение к ВКонтакте

1. **Создайте Mini App:**
   - Перейдите на https://dev.vk.com/mini-apps/get-started
   - Создайте новое приложение

2. **Настройте приложение:**
   - В разделе "Настройки" укажите URL вашего приложения
   - Для тестирования: `https://yourusername.github.io/food-order-app/`
   - Для продакшена: ваш основной домен

3. **Получите App ID:**
   - Скопируйте ID приложения из раздела "Настройки"

4. **Обновите код (опционально):**
   - Если хотите использовать VK WebApp API, раскомментируйте код в `App.jsx`
   - Замените `YOUR_USER_ID` на ваш ID или используйте динамическое получение

## 📦 Используемые технологии
