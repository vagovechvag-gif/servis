# Telegram бот для магазина автозапчастей

Бот для приема заявок на подбор автозапчастей с возможностью отправки VIN номера или фото техпаспорта.

## Функционал

- **Кнопка "Подобрать автозапчасть"** - запуск процесса сбора информации о автомобиле
- **Кнопка "Связаться с менеджером"** - информация для связи с менеджером
- **Запрос данных у клиента:**
  - Марка автомобиля
  - Модель автомобиля
  - Год выпуска
  - VIN номер (текстом) или фото техпаспорта
- **Автоматическая отправка заявки менеджеру** в Telegram

## Требования

- Python 3.8+
- aiogram 3.x
- python-dotenv

## Установка

1. Установите зависимости:
```bash
pip install aiogram python-dotenv
```

2. Создайте файл `.env` в директории проекта:
```bash
cp .env.example .env
```

3. Отредактируйте файл `.env`, указав ваши данные:
```
BOT_TOKEN=ваш_токен_бота
MANAGER_ID=id_менеджера
```

### Получение токена бота

1. Откройте @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в файл `.env`

### Получение ID менеджера

1. Откройте @userinfobot в Telegram
2. Нажмите Start
3. Скопируйте ваш ID в файл `.env`

## Запуск бота

```bash
python auto_parts_bot.py
```

## Как это работает

1. Клиент запускает бота командой `/start`
2. Клиент выбирает "Подобрать автозапчасть"
3. Бот последовательно запрашивает:
   - Марку автомобиля
   - Модель автомобиля
   - Год выпуска
   - VIN номер или фото техпаспорта (можно пропустить)
4. После заполнения всех полей заявка отправляется менеджеру
5. Менеджер получает сообщение со всей информацией о заявке

## Структура заявки менеджера

Менеджер получает сообщение следующего вида:

```
🆕 Новая заявка на подбор запчасти

🚗 Марка: Toyota
📋 Модель: Camry
📅 Год выпуска: 2020
🔢 VIN: JTDBR32E000000000
📷 Фото техпаспорта: Прикреплено

👤 Клиент: @username
🆔 ID: 123456789
🕒 Дата: 10.03.2025 15:30
```

## Примечания

- Бот использует машину состояний (FSM) для последовательного сбора данных
- Поддерживается отправка как текстового VIN, так и фотографий
- Фото техпаспорта пересылается менеджеру вместе с заявкой
- Все сообщения используют Markdown форматирование
